## 2. なぜこの構造が工学的・物理的・理論的に極限効率なのか

剛体パネル折り紙（最大床面積 ~2㎡が物理限界）や曲げアーチ型ドーム（ポール体積が過大）を超越し、等周定理（正12角形＝円の95.5%効率）× テンション膜構造（引張材は座屈せず極薄化可能）× 同心マトリョーシカ・ネスト収納（大径CFRP管の空洞に小径管とアンカー軸を三重収納）を融合。さらに52×16×48cmのCFRP外殻ケース自体を展開時に180°水平開放し、中央マスト支持台座兼フロアテーブルとして活用するゼロ・デッドスペース設計です。

- **等周定理＋垂直1.60m側壁**: 円錐ティピーの弱点（外周50%のデッドスペース）を解消。12本外周支柱により床面積18.75㎡の100%で高さ1.60m以上、71.6%（13.4㎡）で立位1.80m以上を確保。
- **同心マトリョーシカ・ネスト収納**: 中央マスト（OD44→38→32mm）と外周12支柱（OD24→20mm）の空洞に下位管・スプレッダー・320mmアンカー軸24本・チタン床ピン12本を三重収納し、フレーム容積を1/3以下に圧縮。
- **中段0.80mリング＋2重同心アンカー**: 高さ0.80mの中段水平テンションリングと独立45°ガイラインにより、暴風25m/s(90km/h)時の支柱曲げ応力を1/22（16.7 MPa・安全率39倍）へ激減し、全アンカー引抜耐力も余裕確保。
- **完全自立宿泊パッケージ**: 20D Silpoly防水膜(耐水圧3000mm)・30Dバスタブ床(5000mm)・15D防虫メッシュ・Low-E(ε=0.15)結露防止二重屋根ライナーに加え、R=5.2高断熱エアマット×2枚＆USB-C電動ポンプまで52×16×48cmに完全内蔵。

## 5. 1人設営手順（所要約 11.0 分・工具/電源不要）

1. 平地の庭中央にケース(52×16×48cm)を置き180°水平展開→中央台座ロック（約 30 秒）
2. 膜体を放射状に広げ、12頂点のフロア角を110mmチタン床ピンで仮固定（約 90 秒）
3. 中央マスト7節を上から順に差込連結＋中段スプレッダー展開し頂点ハブへ押上自立（約 100 秒）
4. 外周支柱12本（ショックコード内蔵）を1.60mに連結し各軒ポケットへ挿入（約 140 秒）
5. 外周r=4.1m・中段r=3.3mの2重同心リングに320mmダブルヘリカル・スクリュー計24本を手回し固定＆張力調整（約 210 秒）
6. R5.2断熱エアマット2枚をマイクロ電動ポンプで自動膨張（各60秒並列可）→宿泊完了（約 90 秒）
